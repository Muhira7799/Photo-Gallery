# 📸 CSS Flexbox Photo Gallery

A simple **Photo Gallery** built with HTML and CSS as part of a CSS Flexbox learning project. The project displays a collection of images inside a gallery and demonstrates how CSS can be used to control image sizing, borders, and spacing.

## 📌 Features

* Responsive photo gallery structure
* Nine images displayed in the gallery
* Consistent image sizing
* Borders around the gallery and images
* Padding around each image
* Responsive viewport configuration
* Clean and simple layout

## 🛠️ Technologies Used

* **HTML5** – For the page structure and images
* **CSS3** – For styling, sizing, borders, and box sizing

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/CSS-Flexbox-Photo-Gallery.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

The images are loaded from the FreeCodeCamp curriculum, so an internet connection is required to display them.

## 🎨 CSS Concepts Used

The project demonstrates:

* Universal selector (`*`)
* `box-sizing: border-box`
* Percentage-based width
* Image sizing with `width: 100%`
* Borders
* Padding
* CSS classes
* HTML image elements

## 🎯 Learning Objectives

This project helps practice:

* Structuring a photo gallery with HTML
* Linking external images
* Styling images with CSS
* Understanding the CSS box model
* Preparing a layout for Flexbox styling
